# MVelden1.github.io

Persoonlijke portfolio-site van Mick van der Velden.

Live: https://mvelden1.github.io

## Lokaal openen

Open `index.html` direct in de browser, of start een lokale server:

```sh
npx serve
```

## Stack

- Vanilla HTML, CSS en JavaScript, geen build-stap
- Gehost via GitHub Pages
